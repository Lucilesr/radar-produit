# C4 — Candidatures par étape sur mobile

La liste mobile reprend les colonnes personnelles du Kanban, leurs noms, leur ordre et leurs compteurs. Un groupe peut se replier. Les déplacements attendent la réponse du serveur et Closes exige un motif explicite. Notes, entretiens, préparation et bilans restent dans le même dossier. Sur ordinateur, tableau et Kanban restent disponibles. Le sélecteur Étape du téléphone ne modifie pas le statut à l’ouverture.

Le titre de fiche utilise la largeur disponible à390px. Une proposition reçue ne porte plus « En attente de retour ». Une date d’envoi valide ou une clôture historique maintient la candidature dans le suivi ; une offre seulement préparée reste dans Offres.

Recette du staging à compléter avant fusion. Captures avant/après à1360×900 et390×844, compte entièrement fictif avec1000offres et50candidatures. Aucun changement de schéma ni déploiement de production.
