# P7 — Propositions au bon moment

Le moteur commun de prochaine étape décide les travaux et respecte les reports. Des présentations discrètes les rendent accessibles à leur contexte : niveau dans le lot, histoire avant un entretien, source manuelle après le lot. Un bilan privé validé propose le carnet ; une expérience autorisée conserve les termes de P1.

« Plus tard » écrit une échéance de sept jours dans profiles.data.contextualPrompts. Ni la lecture ni un rechargement ne la prolongent. Les écritures atomiques comparent la version du profil et réessaient les changements concurrents ; un formulaire ancien ne peut pas effacer les reports. Aucune migration ni transmission à un service tiers.

Le niveau n’est jamais enregistré au simple affichage. Les quatre boutons de la proposition sont des actions explicites. « Peu importe » est conservé comme choix volontaire sans inventer un niveau pour le score, puis reste modifiable dans les critères. Dans leur éditeur, la validation continue d’attendre « Terminé ».

Les propositions attendent la lecture du compte, gardent leur état en cas d’erreur et ne disparaissent qu’après confirmation. Le focus retrouve la page ou le carnet après repli. Aucun texte de bilan n’est automatiquement recopié ni transmis dans une histoire.
