# Prise en main de Radar

Définissez votre poste dans **Ma recherche**, choisissez vos sources puis actualisez les offres. Le guide accessible dans la navigation accompagne aussi la lecture du CV et la validation des expériences ; les autorisations d’usage restent un choix séparé.

Dans **Opportunités → À examiner**, le lot du jour contient vingt offres au plus. Sa barre indique les décisions prises : sélection, Plus tard ou écartement. Le lot ne se remplit pas pendant le tri. Après sa fin, vous pouvez consulter la réserve ou arrêter pour aujourd’hui. Les archives sont restaurables ; corriger le salaire ne change pas l’âge d’une annonce.

## Fondations Q0

La barre du lot utilise le composant Signal commun. La palette, les compteurs, le radar, les étapes et les écrans de bilan sont prêts pour les lots suivants, sans ajouter de nouvel écran à cette étape. Radar reste sans personnage. Les mouvements respectent la préférence de votre appareil ; les nombres restent lisibles sans animation. Aucun son et aucune donnée envoyée à un service de mesure.
