# Prise en main de Radar

Définissez votre poste dans **Ma recherche**, choisissez vos sources puis actualisez les offres. Le guide accessible dans la navigation accompagne aussi la lecture du CV et la validation des expériences ; les autorisations d’usage restent un choix séparé.

Dans **Opportunités → À examiner**, le lot du jour contient vingt offres au plus. Sa barre indique les décisions prises : sélection, Plus tard ou écartement. Le lot ne se remplit pas pendant le tri. Après sa fin, vous pouvez consulter la réserve ou arrêter pour aujourd’hui. Les archives sont restaurables ; corriger le salaire ne change pas l’âge d’une annonce.

## Fondations Q0

La barre du lot utilise le composant Signal commun. La palette, les compteurs, le radar, les étapes et les écrans de bilan sont prêts pour les lots suivants, sans ajouter de nouvel écran à cette étape. Radar reste sans personnage. Les mouvements respectent la préférence de votre appareil ; les nombres restent lisibles sans animation. Aucun son et aucune donnée envoyée à un service de mesure.

## Un second regard le vendredi — Q1c

Dans **Opportunités → Voir la réserve**, le repêchage propose trois offres proches écartées récemment, lorsqu’il en existe. **Restaurer** les remet dans vos offres ; **Laisser** les garde dans la corbeille et les masque pour cette visite. Le tirage reste stable sur la journée. Cette proposition est facultative et ne modifie jamais vos critères.

## Affiner avec vos tris — Q1d

Après plusieurs offres écartées présentant le même fait, Radar peut proposer **Ajuster mes critères**. Le dialogue est un brouillon : confirmez avec **Enregistrer le critère**, ou annulez. **Non merci** masque cette proposition trente jours, sans changer votre recherche. Une source écartée peut être réactivée dans les critères de **Ma recherche**.

Dans une fiche ouverte, les touches **S**, **L** et **X** sélectionnent, gardent pour plus tard ou écartent. Elles restent sans effet pendant une saisie ou dans un dialogue. Le compteur attend l’enregistrement ; la fiche suivante s’ouvre ensuite. Un lot commencé ne se remplit plus, même s’il comptait moins de vingt offres.

## Actualiser le radar — Q2

**Actualiser** ouvre le balayage des sources automatiques. Le bilan distingue les annonces parcourues, celles selon vos critères, les nouvelles fiches et les doublons déjà présents. **Voir les offres à examiner** revient au tri ; un lot déjà entamé reste figé.

Si une source échoue, ses voisines gardent leurs résultats. **Réessayer** sur sa ligne reprend seulement cette source. Vous pouvez revenir à votre radar pendant la lecture ; une panne conserve vos offres. Une source en pause ou une lecture récente en cache est indiquée séparément. Les sources à visiter, dont Collective et Malt, affichent leur dernière visite : ouvrez la source puis **J’ai fait le tour**. Rien n’est envoyé à un service de mesure.

## Votre séance du jour — Q3

Depuis Aujourd’hui, **Commencer ma séance** propose au plus quatre étapes : trier le lot, faire les relances datées arrivées à échéance, visiter une source non vue depuis plus de cinq jours, valider un bloc du carnet. Les étapes vides sont sautées. L’estimation compte une minute par offre restante, trois par relance et trois pour la visite proposée.

**Étape suivante** permet de passer une étape ; seul ce que vous confirmez compte dans le bilan. Aucun message n’est envoyé au recruteur. Avant C2, les relances viennent des dates choisies dans un bilan d’entretien et leur confirmation reste dans la séance. **Reprendre plus tard** garde la progression pour aujourd’hui ; la reprise est proposée, jamais imposée. **Quitter la séance** reste accessible, y compris dans la fiche d’une candidature ou d’une source. Sans action, vous revenez directement à l’accueil ; sinon, vous voyez le bilan et éventuellement votre meilleure offre sélectionnée. Les pauses ne comptent pas dans les minutes.

La séance reste propre à ce navigateur : mémoire, stockage de session et copie de confort limitée au jour pour retrouver un onglet fermé. Cette copie contient des identifiants et états, aucun texte du CV ni note privée. Sans stockage, la visite courante fonctionne ; un autre appareil ne reprend pas la séance. Le journal L1 apportera ensuite l’historique interne au compte.
