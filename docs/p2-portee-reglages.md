# P2 — les réglages du radar

La présentation expose six réglages en trois groupes et quatre paliers segmentés. Les réglages faits et les autres réglages sont repliés. Seul le prochain réglage reste ouvert, avec sa durée et son action. Le calcul de `lib/radar-reach.ts` reste strictement identique ; aucune donnée, migration ni pondération nouvelle.

SignalProgress conserve la valeur accessible sur10. Ses quatre segments suivent les seuils existants : Repérage0–2, Balayage3–6, Longue portée7–9 et Précision10. Les lignes expliquent l’effet concret de chaque réglage, sans lui attribuer de points visibles.

Les huit thèmes sont dans Mes histoires, sous le carnet. Continuer ouvre cette section et son titre prend le focus. Un choix Signal réunit les thèmes et une action ouvre l’éditeur déjà existant. Les récits sans thème continuent de compter pour le réglage Quatre histoires ; le compteur sur8 décrit uniquement les thèmes couverts.

La prochaine action vient encore de la règle Q4 ; P4 la remplacera par le moteur central, dans l’ordre demandé. P6 retirera la portée compacte de l’accueil. Aucune modification anticipée de ces lots. Recette et captures avant/après : `p2-portee-reglages/README.md`.
