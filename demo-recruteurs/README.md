# Radar Produit — Démo recruteurs

Démo publique et autonome de Radar Produit. Les entreprises, offres, profil, échéances et résultats sont fictifs. Elle ne charge ni le site privé, ni sa base, ni un connecteur. Les interactions sont enregistrées uniquement dans le `localStorage` du navigateur et peuvent être réinitialisées depuis le pied de page.

La vue d'accueil montre immédiatement le radar renseigné. La visite guidée facultative explique les critères de départ, le tri et le passage en candidature.

Site statique : `dist/index.html`, `dist/style.css`, `dist/app.js`. Les dates de démonstration sont calculées à partir de la date de visite afin que le lien reste présentable dans le temps.
